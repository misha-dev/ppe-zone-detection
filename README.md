# Распознавание СИЗ и опасных зон (ТЗ 5)

Веб-сервис: пользователь загружает фото на фронтенд, бэкенд передаёт его нейросетям, которые находят людей без каски или жилета в опасной зоне. Результат - фото с рамками, зоной и вердиктом.

## Стек

- Фронтенд: React, TypeScript, Zustand, TanStack Query
- Бэкенд: NestJS, TypeScript
- Нейросети: Python, FastAPI, ultralytics (YOLO), shapely
- Запуск: Docker

## Структура

```
tasks/           - ТЗ и шаблоны КТ
completedTasks/  - заполненные КТ
code/front/      - фронтенд
code/back/       - бэкенд
code/ml/         - нейросети
```

## Этапы

- КТ 1 - старт и бизнес-процессы
- КТ 2 - анализ и данные
- КТ 3 - эксперименты
- КТ 4 - прототип
- КТ 5 - приёмка и защита
