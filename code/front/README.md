# Фронтенд

Веб-интерфейс: загрузка фото, разметка опасной зоны, показ результата.

## Стек

| Что | Чем |
|---|---|
| Язык | TypeScript |
| UI | React |
| Сборка | Vite |
| Состояние | Zustand (фото, точки зоны, результат) |
| Запросы к бэкенду | TanStack Query |
| Рисование зоны и рамок | HTML Canvas |
| Запуск | Docker (nginx) |

## Экраны

1. Загрузка фото.
2. Отметка опасной зоны кликами по фото (многоугольник).
3. Результат: фото с рамками людей/СИЗ и зоной, вердикт «есть нарушение / нет», список нарушителей.
