# Фронтенд

Веб-интерфейс: загрузка фото и показ результата. Опасной зоной считается всё фото.

## Стек

| Что | Чем |
|---|---|
| Язык | TypeScript |
| UI | React |
| Сборка | Vite |
| Состояние | Zustand (фото, результат) |
| Запросы к бэкенду | TanStack Query |
| Рисование рамок | HTML Canvas |
| Запуск | Docker (nginx) |

## Экраны

1. Загрузка фото и кнопка «Проверить».
2. Результат: фото с рамками людей, вердикт «есть нарушение / нет», список нарушителей.

## Запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:5173`. Запросы `/api` проксируются на бэкенд `http://localhost:3000` (меняется через `VITE_PROXY_TARGET`). В Docker это делает nginx.
