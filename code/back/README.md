# Бэкенд

Принимает фото от фронтенда, передаёт его в сервис нейросетей и возвращает результат. Опасной зоной считается всё фото.

## Стек

| Что | Чем |
|---|---|
| Язык | TypeScript |
| Фреймворк | NestJS |
| Загрузка файлов | Multer (встроен в NestJS) |
| Проверка входных данных | Multer (тип и размер), image-size (фото читается) |
| Запросы к сервису нейросетей | @nestjs/axios |
| Документация API | Swagger (@nestjs/swagger) |
| Запуск | Docker |

База данных для MVP не нужна.

## API

`POST /api/detect` - принимает фото (multipart, поле `image`), возвращает:

```json
{
  "violation": true,
  "people": [
    { "box": [120, 220, 180, 400], "helmet": false, "vest": true, "violation": true }
  ]
}
```

Ошибки: `400` — нет фото или его не удалось прочитать, `413` — фото больше 10 МБ, `415` — не JPEG/PNG/WebP, `502` — сервис нейросетей недоступен.

Swagger: `http://localhost:3000/api/docs`. Проверка живости: `GET /api/health`.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `ML_URL` | `http://localhost:8000` | Адрес сервиса нейросетей |
| `ML_MOCK` | `false` | `true` — не ходить в ML, вернуть тестовый ответ (3 человека, двое без СИЗ) |

## Контракт с сервисом нейросетей

Бэкенд шлёт `POST {ML_URL}/detect` (multipart): поле `image` — фото. Ожидает ответ в том же формате, что и `POST /api/detect`.

## Запуск

```bash
npm install
ML_MOCK=true npm run start:dev
```
