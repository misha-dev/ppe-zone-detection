# Бэкенд

Принимает фото и зону от фронтенда (сейчас фронтенд шлёт зону по границам всего фото), передаёт их в сервис нейросетей и возвращает результат.

## Стек

| Что | Чем |
|---|---|
| Язык | TypeScript |
| Фреймворк | NestJS |
| Загрузка файлов | Multer (встроен в NestJS) |
| Проверка входных данных | class-validator |
| Запросы к сервису нейросетей | @nestjs/axios |
| Документация API | Swagger (@nestjs/swagger) |
| Запуск | Docker |

База данных для MVP не нужна.

## API

`POST /api/detect` - принимает фото (multipart) и точки зоны (JSON), возвращает:

```json
{
  "violation": true,
  "zone": [[100, 200], [400, 200], [400, 500], [100, 500]],
  "people": [
    { "box": [120, 220, 180, 400], "helmet": false, "vest": true, "inZone": true, "violation": true }
  ]
}
```

Ошибки: `400` — нет фото или неверная зона, `413` — фото больше 10 МБ, `415` — не JPEG/PNG/WebP, `502` — сервис нейросетей недоступен.

Swagger: `http://localhost:3000/api/docs`. Проверка живости: `GET /api/health`.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `ML_URL` | `http://localhost:8000` | Адрес сервиса нейросетей |
| `ML_MOCK` | `false` | `true` — не ходить в ML, вернуть тестовый ответ (3 человека внутри зоны) |

## Контракт с сервисом нейросетей

Бэкенд шлёт `POST {ML_URL}/detect` (multipart): поле `image` — фото, поле `zone` — JSON с точками зоны. Ожидает ответ в том же формате, что и `POST /api/detect`.

## Запуск

```bash
npm install
ML_MOCK=true npm run start:dev
```
