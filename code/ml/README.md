# Нейросети (ML)

Сервис получает фото и зону, находит людей, каски и жилеты, проверяет нарушения и возвращает результат бэкенду.

## Стек

| Что | Чем |
|---|---|
| Язык | Python 3.11 |
| API | FastAPI + uvicorn |
| Детекция | ultralytics (YOLO) |
| Проверка «в зоне» | shapely |
| Работа с фото | OpenCV / Pillow |
| Обучение | Google Colab или Kaggle (бесплатная GPU) |
| Запуск | Docker |

## Как работает (MVP)

1. **Детекция.** Одна модель YOLO, дообученная на открытом датасете СИЗ (Hard Hat Workers или Construction Site Safety с Roboflow). Классы: человек, каска, жилет.
2. **СИЗ надет.** Рамка каски или жилета пересекается с рамкой человека.
3. **Человек в зоне.** Нижняя середина рамки (точка ног) внутри многоугольника зоны.
4. **Нарушение.** Человек в зоне и на нём нет каски или жилета.

## Сравнение моделей

Для отчёта сравниваем 3-4 готовые модели ultralytics (например, YOLOv8n, YOLOv8s, YOLO11n, YOLO11s): обучаем на одном датасете, проверяем на одних тестовых фото. Метрики: Precision, Recall, время на фото, память. В сервис берём лучшую.
